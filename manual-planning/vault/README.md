# Manual Planning Vault

This directory serves as a vault (archive) for historical context, past grilling sessions, superseded design specifications, and deprecated code reviews.

These files are preserved here to maintain repository history and decision provenance without cluttering the active specifications and planning files in the project.

## Directory Structure

- [architecture/](./architecture/): Contains general backend/monorepo architecture grilling files.
- [code-reviews/](./code-reviews/): Contains historical code review logs from past feature reshapes.
- [handoff-sessions/](./handoff-sessions/): Contains past handoff files, accompanied by a consolidated [HISTORY.md](./handoff-sessions/HISTORY.md) index file.
- [DESIGN.md](./DESIGN.md): Historical design rules, superseded by the canonical [apps/web/DESIGN.md](../../apps/web/DESIGN.md).
