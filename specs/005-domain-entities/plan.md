## Summary

Create the core domain entity layer for the Church Volunteer Scheduling Platform. This involves two locations: (1) a new `packages/core` package containing the reusable `Entity<T>` base class and `DomainError` base class — primitives shared across projects, and (2) 12 concrete domain entities inside `packages/api/src/domain/` following the 4-layer Clean Architecture blueprint. Entities have `protected` props, dedicated read-only getters, encapsulated mutation methods, and constructor-level date range invariant enforcement as a failsafe. The `EntityMapper` interface contract is also defined in the domain layer.
